# CC98 Cleaner

CC98 Cleaner 是一个面向 CC98 的浏览器扩展，用于减少浏览帖子时接触到的侮辱、嘲讽、阴阳怪气、攻击性指责等高戾气评论。扩展会在帖子页面加载后自动分析每条回复，并按设定阈值直接隐藏命中的内容，避免用醒目的折叠提示再次打扰阅读。

识别由短句规则、中文语义向量和本地分类器共同完成，不依赖远程 AI 接口，也不会上传正在浏览的评论。你可以只在指定版面启用过滤、调整严格程度，并随时查看原文或将误判内容设为“以后保留”。除内容过滤外，扩展还可清理踩数及负面风评记录，让页面更安静。

项目主要支持 Microsoft Edge，也兼容其他 Chromium 浏览器。模型并不保证判断完全准确，建议从下方推荐设置开始，再根据自己的感受微调。

## 功能

- 清零页面中的踩数显示；
- 隐藏“风评值 -1”记录；
- 使用规则、`bge-small-zh-v1.5` 向量和本地线性分类器识别戾气；
- 默认直接隐藏命中评论，可选择显示提示与“查看原文”按钮；
- 帖子一楼正文始终保留，不参与攻击性评论过滤；
- 支持调整过滤阈值和保存“以后保留”反馈；
- 可启用“仅在所选版面过滤”，在可搜索的多选栏中选择版面；该范围只限制评论内容过滤，清零踩数和隐藏负面风评仍对所有版面生效。

所有判断均在浏览器本地完成。约 24 MB 的量化 BGE 模型已包含在 Release 安装包中，安装后无需再从模型网站下载。

## 推荐设置

- 推荐过滤阈值：`0.43`；
- 推荐过滤版面：`郁闷小屋`、`心灵之约`、`健康卫士`；
- 如果误隐藏较多，可逐步提高到 `0.46～0.50`；
- 如果更重视不漏掉戾气评论，可在 `0.40～0.43` 之间调整。

## 从 Release 安装

浏览器不能直接加载 ZIP 文件，需要先解压一次；之后更新版本时重复以下步骤即可。

### Microsoft Edge

1. 打开 [Releases](https://github.com/Aleph-000/cc98-cleaner/releases)，下载最新版 `cc98-cleaner-v*.zip`；
2. 右键 ZIP 文件并选择“全部解压缩”；
3. 在 Edge 打开 `edge://extensions`，开启“开发人员模式”；
4. 点击“加载解压缩的扩展”，选择刚解压且包含 `manifest.json` 的文件夹。

### Google Chrome

1. 下载并解压同一个 Release ZIP；
2. 在 Chrome 打开 `chrome://extensions`，开启“开发者模式”；
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。

安装完成后，建议将扩展固定到工具栏，打开设置并选择需要过滤的版面。不要删除已加载的解压文件夹，否则浏览器可能无法继续使用或更新扩展。

## 从源码构建安装

需要先安装 Node.js 18 或更高版本。仓库已包含运行所需的量化 BGE 模型，构建时不需要另外下载模型文件。

```powershell
git clone https://github.com/Aleph-000/cc98-cleaner.git
cd cc98-cleaner
npm install
npm run build
npm run check
```

构建完成后，在 Edge 的 `edge://extensions` 或 Chrome 的 `chrome://extensions` 中开启开发人员模式，点击“加载解压缩的扩展”，选择仓库中的 `dist` 文件夹。

## 隐私

扩展不会上传评论正文。仓库及发布包不包含用户名、楼层信息、提示词、访问令牌或本机路径；随扩展发布的分类器与种子文件仅包含运行所需的数值参数和向量，版面列表只包含公开的分区名、版面 ID 和名称。
