# CC98 Cleaner

CC98 Cleaner 是一个在浏览器本地识别并隐藏高戾气评论的 Edge/Chrome 扩展。

## 功能

- 清零页面中的踩数显示；
- 隐藏“风评值 -1”记录；
- 使用规则、`bge-small-zh-v1.5` 向量和本地线性分类器识别戾气；
- 默认直接隐藏命中评论，可选择显示提示与“查看原文”按钮；
- 支持调整过滤阈值和保存“以后保留”反馈。

所有判断均在浏览器本地完成。首次启用向量模型时会下载约 24 MB 权重，之后使用浏览器缓存。

## 构建

```powershell
npm install
npm run build
npm run check
```

构建结果位于 `dist/`。

## Edge 安装

1. 打开 `edge://extensions`；
2. 开启“开发人员模式”；
3. 点击“加载解压缩的扩展”；
4. 选择仓库中的 `dist` 文件夹。
